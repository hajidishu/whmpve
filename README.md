# WHMPVE

WHMPVE是一个开源的whmcs对接pve自动化售卖lxc容器和kvm虚拟机的方案

之所以要开发WHMPVE是因为我发现竟然都2026年了，仍然没有一个免费且功能完善的whmcs对接pve方案，在以前你要么使用开源的半成品方案，要么付费使用模块花园的商业解决方案
